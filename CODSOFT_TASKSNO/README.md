# CODSOFT Java Development Internship

This repository contains the projects completed as part of my CodSoft Java Development Internship.

## Projects Completed

### Task 1 - Student Grade Calculator

A web-based application that calculates total marks, average percentage and grade based on marks entered by the student.

### Task 2 - ATM Interface

A web-based ATM simulation that provides balance checking, deposit and withdrawal functionality with input validation.

### Task 3 - Quiz Application with Timer

A web-based quiz application containing multiple-choice questions, a timer, answer validation, score calculation and final results.

## How to Run

1. Clone this repository.
2. Open the required project folder in VS Code.
3. Open `index.html`.
4. Run the project using Live Server.
